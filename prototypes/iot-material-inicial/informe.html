02 / INTRODUCCIÓN

Del dado físico a un evento digital

FRAGUA necesita vincular una tirada sobre la mesa con un resultado utilizable por su ecosistema. La carga manual interrumpe el juego y puede introducir errores. Este proyecto explora una interfaz IoT que obtiene evidencia visual y propone una lectura verificable.

La ESP32-CAM conecta sensores y un actuador con una API a través de Wi-Fi. El HC-SR501 detecta cambios infrarrojos asociados al gesto de la mano; no detecta de forma fiable un pequeño dado ni determina su reposo. El sistema espera, toma tres fotos y analiza la estabilidad visual.

Primera etapa

Montaje físico seguro, disparo PIR, señal luminosa y recepción de JPEG claros.

Segunda etapa

Reconocimiento experimental de un d6 y contrato de integración futura con FRAGUA.

Alcance implementado: un d6 blanco de puntos negros. Dados poliédricos numerados y múltiples dados requieren otro reconocedor y validación propia.

03 / OBJETIVOS

Objetivos verificables

General

Construir y validar un prototipo físico IoT que convierta el gesto de una tirada en evidencia fotográfica y una propuesta de resultado revisable para FRAGUA.

  1. Conectar PIR y cámara con alimentación común, sin aplicar 5 V a GPIO.
  2. Activar un LED durante 80 ms como respuesta observable al disparo.
  3. Capturar tres JPEG por evento, con espera inicial configurable.
  4. Transmitir y conservar imágenes identificadas por dispositivo, tirada y fotograma.
  5. Proponer la lectura de un d6 o abstenerse ante ambigüedad.
  6. Medir capturas útiles, cobertura, exactitud y latencia en un conjunto físico etiquetado.
  7. Exponer un evento confirmado e idempotente para una futura integración.

Metas propuestas, no resultados: al menos 27/30 tiradas con una foto útil; reportar por separado todos los errores y rechazos. No se fija una exactitud prometida antes de medir.

05 / DIAGRAMA DE BLOQUES

Arquitectura y flujo de información

El PC aporta almacenamiento y cómputo. La ESP32 no interpreta el dado. La flecha discontinua representa una integración todavía no conectada.

Estados y tratamiento de errores

Calentamiento 60 s → listo tras LOW → gesto → LED y espera 2,5 s → tres fotos → espera 5 s y LOW. Fallo inicial de cámara: bloqueo hasta reinicio. Sin red: registro y descarte, sin cola offline. Una captura fallida mantiene la tirada incompleta; no se inventa resultado.

Esquema lógico para AI Thinker, no dibujo de posición física de pines. Verificar etiquetas y acceso con la base conectada; no cablear por orientación de esta figura.

  1. Desenchufar USB, verificar serigrafía y alinear la placa/base.
  2. Conectar VCC, GND y OUT según etiquetas; nunca enviar 5 V a GPIO.
  3. Dejar SD vacía y GPIO0 libre durante funcionamiento.
  4. Alimentar por una única fuente USB estable; comprobar primero cámara y luego PIR.

08 / HARDWARE Y SOFTWARE

Responsabilidades claras

Dispositivo físico

ESP32-CAM: temporización, cámara y Wi-Fi. OV3660: sensor de imagen. HC-SR501: disparador por gesto. LED GPIO4: señal de activación. Base USB-C: base programadora según compra; chip USB y mapa de pines por verificar.

JPEG VGA con PSRAM, QVGA de respaldo. Un buffer evita retener múltiples imágenes grandes en memoria.

Software local

Arduino ESP32 2.0.17: firmware C++ comentado. PlatformIO 6.9.0 (plataforma Espressif32): configuración reproducible. Node.js 22 + sharp 0.34.5: API y procesamiento.

Archivos JPEG y JSON por tirada; clave de acceso; validación de formato/tamaño; idempotencia por fotograma; confirmación humana.

Cómo se reconoce y qué puede fallar

Se segmenta una única región clara grande sobre fondo oscuro; se cuentan manchas oscuras de tamaño y forma compatibles con puntos. Se comparan las fotos 1 y 2: igual candidato y diferencia media menor a 3/255. Es una heurística experimental, sin modelo de probabilidad ni garantía de reconocer un dado real. Reflejos, caras laterales, otros objetos y desenfoque pueden producir errores.

La API produce un contrato para FRAGUA; no está integrada a una partida real. El soporte universal de dados permanece pendiente.

// FRAGUA lab: AI Thinker ESP32-CAM / OV3660, Arduino ESP32 2.0.17.
// No SD card: GPIO13 is PIR input, GPIO4 drives the onboard flash LED.
#include <Arduino.h>
#include <WiFi.h>
#include <HTTPClient.h>
#include "esp_camera.h"
#if __has_include("secrets.h")
#include "secrets.h"
#else
#include "secrets.example.h"
#endif

constexpr int PIR_PIN = 13, LED_PIN = 4;
constexpr uint32_t WARMUP_MS = 60000, SETTLE_MS = 2500;
constexpr uint32_t GAP_MS = 700, COOLDOWN_MS = 5000;
enum class State { Warmup, Ready, Settling, Capturing, Rearm, Fault };
State state = State::Warmup;
uint32_t stateAt = 0, lastWifiAttempt = 0;
bool seenLow = false;
unsigned frameIndex = 0, sequence = 0;
String bootId, rollId;

void enter(State next) { state = next; stateAt = millis(); }

bool initCamera() {
  camera_config_t c = {};
  c.ledc_channel = LEDC_CHANNEL_0; c.ledc_timer = LEDC_TIMER_0;
  c.pin_d0 = 5; c.pin_d1 = 18; c.pin_d2 = 19; c.pin_d3 = 21;
  c.pin_d4 = 36; c.pin_d5 = 39; c.pin_d6 = 34; c.pin_d7 = 35;
  c.pin_xclk = 0; c.pin_pclk = 22; c.pin_vsync = 25; c.pin_href = 23;
  c.pin_sccb_sda = 26; c.pin_sccb_scl = 27;
  c.pin_pwdn = 32; c.pin_reset = -1; c.xclk_freq_hz = 20000000;
  c.pixel_format = PIXFORMAT_JPEG;
  c.frame_size = psramFound() ? FRAMESIZE_VGA : FRAMESIZE_QVGA;
  c.jpeg_quality = 12; c.fb_count = 1;
  c.fb_location = psramFound() ? CAMERA_FB_IN_PSRAM : CAMERA_FB_IN_DRAM;
  c.grab_mode = CAMERA_GRAB_WHEN_EMPTY;
  esp_err_t result = esp_camera_init(&c);
  Serial.printf("camera_init=0x%x psram=%d\n", result, psramFound());
  return result == ESP_OK;
}

void captureAndSend() {
  // Flush queued exposure. The light is OFF during capture to limit reflections.
  camera_fb_t *stale = esp_camera_fb_get();
  if (stale) esp_camera_fb_return(stale);
  camera_fb_t *fb = esp_camera_fb_get();
  if (!fb) { Serial.println("capture_failed"); return; }
  Serial.printf("roll=%s frame=%u jpeg_bytes=%u\n", rollId.c_str(), frameIndex, unsigned(fb->len));
  if (WiFi.status() == WL_CONNECTED) {
    WiFiClient client;
    HTTPClient http;
    http.setConnectTimeout(3000); http.setTimeout(5000);
    // HTTP is only for an isolated trusted LAN. Production requires TLS.
    if (http.begin(client, API_URL)) {
      http.addHeader("Content-Type", "image/jpeg");
      http.addHeader("Authorization", String("Bearer ") + API_TOKEN);
      http.addHeader("X-Device-Id", DEVICE_ID);
      http.addHeader("X-Roll-Id", rollId);
      http.addHeader("X-Frame-Index", String(frameIndex));
      int status = http.POST(fb->buf, fb->len);
      Serial.printf("http=%d\n", status);
      if (status > 0) Serial.println(http.getString());
      http.end();
    }
  } else {
    Serial.println("offline_capture_discarded: no SD/offline queue");
  }
  // Always release the frame, even on network failure.
  esp_camera_fb_return(fb);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT); digitalWrite(LED_PIN, LOW);
  pinMode(PIR_PIN, INPUT_PULLDOWN);
  bootId = String(esp_random(), HEX) + String(esp_random(), HEX);
  if (!initCamera()) { enter(State::Fault); return; }
  WiFi.mode(WIFI_STA); WiFi.setAutoReconnect(true);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  lastWifiAttempt = millis();
  Serial.println("PIR warmup 60s; then LOW required. Serial 'c' = manual capture.");
  enter(State::Warmup);
}

void loop() {
  if (state == State::Fault) { delay(100); return; }
  const uint32_t now = millis();
  if (WiFi.status() != WL_CONNECTED && now - lastWifiAttempt >= 15000) {
    WiFi.reconnect(); lastWifiAttempt = now;
  }
  const bool high = digitalRead(PIR_PIN) == HIGH;
  const bool manual = Serial.available() && Serial.read() == 'c';
  switch (state) {
    case State::Warmup:
      if (now - stateAt >= WARMUP_MS) { seenLow = false; enter(State::Ready); }
      break;
    case State::Ready:
      if (!high) seenLow = true;
      if (manual || (seenLow && high)) {
        rollId = bootId + "-" + String(++sequence); frameIndex = 0;
        Serial.printf("trigger=%s roll=%s\n", manual ? "manual" : "PIR", rollId.c_str());
        digitalWrite(LED_PIN, HIGH); enter(State::Settling);
      }
      break;
    case State::Settling:
      // Visible 80ms pulse proves actuator command, not its physical operation.
      if (now - stateAt >= 80) digitalWrite(LED_PIN, LOW);
      if (now - stateAt >= SETTLE_MS) enter(State::Capturing);
      break;
    case State::Capturing:
      if (frameIndex == 0 || now - stateAt >= GAP_MS) {
        captureAndSend(); ++frameIndex; stateAt = millis();
        if (frameIndex == 3) enter(State::Rearm);
      }
      break;
    case State::Rearm:
      // Requires LOW after capture; prevents repeated rolls while PIR stays HIGH.
      if (!high && now - stateAt >= COOLDOWN_MS) {
        seenLow = false; enter(State::Ready); Serial.println("ready");
      }
      break;
    default: break;
  }
  delay(5);
}

import http from 'node:http';
import { mkdir, readFile, writeFile, rename } from 'node:fs/promises';
import path from 'node:path';
import { createHash, timingSafeEqual } from 'node:crypto';
import { fileURLToPath } from 'node:url';
import { recognize, compareFrames } from './recognizer.mjs';

const safeId = /^[A-Za-z0-9_-]{1,80}$/;
const MAX_BYTES = 1024 * 1024;
const hash = b => createHash('sha256').update(b).digest('hex');
async function jsonFile(file) { try { return JSON.parse(await readFile(file, 'utf8')); } catch (e) { if (e.code === 'ENOENT') return null; throw e; } }
async function save(file, value) { await writeFile(file + '.tmp', JSON.stringify(value, null, 2)); await rename(file + '.tmp', file); }
function send(res, status, value) { res.writeHead(status, { 'Content-Type': 'application/json', 'Cache-Control': 'no-store' }); res.end(JSON.stringify(value)); }
async function body(req, max = MAX_BYTES) {
  let size = 0; const chunks = [];
  for await (const chunk of req) { size += chunk.length; if (size > max) throw Object.assign(new Error('payload_too_large'), { status: 413 }); chunks.push(chunk); }
  return Buffer.concat(chunks);
}

export function createApi({ token, dir }) {
  if (!token || token.length < 20) throw new Error('Set API_TOKEN with at least 20 characters');
  let busy = false;
  return http.createServer(async (req, res) => {
    const url = new URL(req.url, 'http://localhost');
    if (req.method === 'GET' && url.pathname === '/health') return send(res, 200, { status: 'ok', recognition: 'experimental-d6-only' });
    const supplied = hash(Buffer.from(req.headers.authorization || ''));
    const expected = hash(Buffer.from(`Bearer ${token}`));
    if (!timingSafeEqual(Buffer.from(supplied), Buffer.from(expected))) return send(res, 401, { error: 'unauthorized' });
    // Single writer keeps frame/confirmation updates atomic. Lab server: no multi-process deployment.
    if (busy) return send(res, 503, { error: 'busy_retry_later' });
    busy = true;
    try {
      if (req.method === 'POST' && url.pathname === '/v1/captures') {
        if (req.headers['content-type']?.split(';')[0] !== 'image/jpeg') return send(res, 415, { error: 'expected_image_jpeg' });
        const device = req.headers['x-device-id'], roll = req.headers['x-roll-id'];
        const index = req.headers['x-frame-index'];
        if (!safeId.test(device || '') || !safeId.test(roll || '') || !/^[0-2]$/.test(index || '')) return send(res, 400, { error: 'invalid_capture_headers' });
        const jpeg = await body(req);
        if (jpeg[0] !== 255 || jpeg[1] !== 216) return send(res, 422, { error: 'invalid_jpeg' });
        const folder = path.join(dir, device, roll); await mkdir(folder, { recursive: true });
        const file = path.join(folder, 'roll.json');
        let record = await jsonFile(file) || { schema_version: 1, device_id: device, roll_id: roll, sides: 6, status: 'pending', value: null, frames: {}, created_at: new Date().toISOString() };
        if (record.frames[index]) {
          if (record.frames[index].sha256 !== hash(jpeg)) return send(res, 409, { error: 'frame_id_conflict' });
          return send(res, 200, record);
        }
        if (record.status === 'confirmed') return send(res, 409, { error: 'roll_already_confirmed' });
        let result;
        try { result = await recognize(jpeg); } catch { return send(res, 422, { error: 'invalid_or_oversized_image' }); }
        await writeFile(path.join(folder, `${index}.jpg`), jpeg);
        record.frames[index] = { sha256: hash(jpeg), value: result.value, reason: result.reason, received_at: new Date().toISOString() };
        if (Object.keys(record.frames).length === 3) {
          const a = await recognize(await readFile(path.join(folder, '1.jpg')));
          const b = await recognize(await readFile(path.join(folder, '2.jpg')));
          record.mean_difference = compareFrames(a.pixels, b.pixels);
          record.status = 'review_required';
          record.candidate_value = a.value !== null && a.value === b.value && record.mean_difference < 3 ? b.value : null;
          record.reason = record.candidate_value === null ? 'unstable_or_ambiguous' : 'candidate_requires_human_confirmation';
        }
        await save(file, record); return send(res, 201, record);
      }
      const match = /^\/v1\/rolls\/([A-Za-z0-9_-]{1,80})\/([A-Za-z0-9_-]{1,80})(?:\/(confirm|[0-2]\.jpg|event))?$/.exec(url.pathname);
      if (!match) return send(res, 404, { error: 'not_found' });
      const [, device, roll, action] = match, folder = path.join(dir, device, roll), file = path.join(folder, 'roll.json');
      const record = await jsonFile(file);
      if (!record) return send(res, 404, { error: 'roll_not_found' });
      if (req.method === 'GET' && !action) return send(res, 200, record);
      if (req.method === 'GET' && action?.endsWith('.jpg')) {
        if (!record.frames[action[0]]) return send(res, 404, { error: 'frame_not_found' });
        const bytes = await readFile(path.join(folder, action));
        res.writeHead(200, { 'Content-Type': 'image/jpeg', 'Cache-Control': 'no-store' }); return res.end(bytes);
      }
      if (req.method === 'POST' && action === 'confirm') {
        let input; try { input = JSON.parse(await body(req, 2048)); } catch (e) { if (e.status) throw e; return send(res, 400, { error: 'invalid_json' }); }
        if (!Number.isInteger(input?.value) || input.value < 1 || input.value > 6 || typeof input?.reviewer !== 'string' || !input.reviewer.trim() || input.reviewer.length > 80)
          return send(res, 400, { error: 'value_1_to_6_and_reviewer_required' });
        if (record.status === 'pending') return send(res, 409, { error: 'incomplete_burst' });
        if (record.status === 'confirmed') return record.value === input.value ? send(res, 200, record) : send(res, 409, { error: 'already_confirmed_different_value' });
        record.status = 'confirmed'; record.value = input.value; record.reviewer = input.reviewer.trim(); record.confirmed_at = new Date().toISOString();
        await save(file, record); return send(res, 200, record);
      }
      if (req.method === 'GET' && action === 'event') {
        if (record.status !== 'confirmed') return send(res, 409, { error: 'confirmation_required' });
        return send(res, 200, { schema_version: 1, type: 'dice.roll.confirmed', event_id: `${device}:${roll}`, device_id: device, roll_id: roll, sides: 6, value: record.value, confirmed_at: record.confirmed_at, provenance: 'human_review_of_camera_capture' });
      }
      return send(res, 405, { error: 'method_not_allowed' });
    } catch (error) {
      if (!res.headersSent) send(res, error.status || 500, { error: error.status ? error.message : 'internal_error' });
      console.error(error.message);
    } finally { busy = false; }
  });
}

if (process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])) {

}
backend/recognizer.mjs
import sharp from 'sharp';

// Connected components, 4-neighbour adjacency. Background pixels never enter a group.
function components(mask, w, h) {
  const seen = new Uint8Array(mask.length), groups = [];
  for (let start = 0; start < mask.length; start++) {
    if (!mask[start] || seen[start]) continue;
    const stack = [start]; seen[start] = 1;
    let area = 0, x0 = w, y0 = h, x1 = 0, y1 = 0, sx = 0, sy = 0;
    while (stack.length) {
      const p = stack.pop(), x = p % w, y = Math.floor(p / w);
      area++; sx += x; sy += y;
      x0 = Math.min(x0, x); x1 = Math.max(x1, x); y0 = Math.min(y0, y); y1 = Math.max(y1, y);
      const neighbours = [];
      if (x > 0) neighbours.push(p - 1); if (x + 1 < w) neighbours.push(p + 1);
      if (y > 0) neighbours.push(p - w); if (y + 1 < h) neighbours.push(p + w);
      for (const q of neighbours) if (mask[q] && !seen[q]) { seen[q] = 1; stack.push(q); }
    }
    groups.push({ area, x0, y0, x1, y1, x: sx / area, y: sy / area });
  }
  return groups;
}

export async function recognize(jpeg) {
  const decoder = sharp(jpeg, { limitInputPixels: 4000000, failOn: 'error' });
  const meta = await decoder.metadata();
  if (meta.format !== 'jpeg') throw new Error('Expected a decoded JPEG');
  const { data, info } = await decoder.resize(320, 240, { fit: 'fill' }).greyscale().raw().toBuffer({ resolveWithObject: true });
  const w = info.width, h = info.height;
  const reject = reason => ({ value: null, reason, pixels: data });
  // Controlled scene: one white die, dark matte tray, camera perpendicular to top face.
  const white = Uint8Array.from(data, v => v > 165 ? 1 : 0);
  const faces = components(white, w, h).filter(g => g.area > 900);
  if (faces.length !== 1) return reject('expected_one_white_face');
  const f = faces[0], fw = f.x1 - f.x0 + 1, fh = f.y1 - f.y0 + 1;
  if (f.x0 < 3 || f.y0 < 3 || f.x1 > w - 4 || f.y1 > h - 4 || fw / fh < .65 || fw / fh > 1.5)
    return reject('face_cropped_or_perspective');
  const margin = Math.max(3, Math.round(Math.min(fw, fh) * .07));
  const mask = new Uint8Array(data.length);
  for (let y = f.y0 + margin; y <= f.y1 - margin; y++)
    for (let x = f.x0 + margin; x <= f.x1 - margin; x++)
      if (data[y * w + x] < 85) mask[y * w + x] = 1;
  const blobs = components(mask, w, h).filter(g => g.area >= 8);
  const pips = blobs.filter(g => {
    const bw = g.x1 - g.x0 + 1, bh = g.y1 - g.y0 + 1;
    const ratio = bw / bh, fraction = g.area / (fw * fh);
    return ratio > .55 && ratio < 1.8 && fraction > .003 && fraction < .065 &&
      g.area / (bw * bh) > .45 && g.x0 > f.x0 + margin && g.x1 < f.x1 - margin &&
      g.y0 > f.y0 + margin && g.y1 < f.y1 - margin;
  });
  if (pips.length !== blobs.length || pips.length < 1 || pips.length > 6) return reject('ambiguous_pips');
  const areas = pips.map(p => p.area);
  if (Math.max(...areas) / Math.min(...areas) > 2) return reject('unequal_pips');
  return { value: pips.length, reason: 'heuristic_d6_candidate', pixels: data };
}

export function compareFrames(a, b) {
  if (!a || !b || a.length !== b.length) return Infinity;
  let sum = 0;
  for (let i = 0; i < a.length; i++) sum += Math.abs(a[i] - b[i]);
  return sum / a.length; // Mean absolute grayscale difference, 0..255, not probability.
}

12 / CONCLUSIONES Y MEJORAS

Un prototipo defendible necesita evidencia

El diseño conecta sensores, procesamiento, comunicación y un actuador observable. El software permite recorrer el flujo completo hasta un evento confirmado, bajo un escenario visual acotado. Todavía no se puede concluir que el sistema físico funciona ni que alcanza una precisión determinada.

La principal limitación es usar la presencia de una mano como aproximación al inicio de una tirada. El retardo fijo y la comparación de dos imágenes reducen algunos errores, pero no demuestran reposo continuo. La revisión humana evita propagar automáticamente una lectura equivocada.
